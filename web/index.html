How your data stays private

  • This page is a set of static files. Python runs inside your browser using Pyodide, which is served from this same site.
  • When you choose a file, the browser reads it into this tab’s memory. The conversion runs in the tab, and the CSV download is created in the tab.
  • The page’s Content Security Policy tells the browser to block any connection to other websites, and there is no server here that accepts uploads.
  • Nothing about employees is written to storage. Closing the tab or clicking Clear everything discards it.

Check it yourself: open the browser’s developer tools (F12), go to the Network tab, then choose your files and download the result. No requests should appear after the page finishes loading.
